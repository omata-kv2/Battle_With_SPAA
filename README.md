# Cooking With SPAA v5.7

## v5.7 アップデート概要

### 1. エアストライクモードの完全削除
- `AIR_STRIKE` モードおよび関連マップ・UI・同期処理をすべて削除しました（出撃ゲートは `FALL MISSILE` 専用となります）。

### 2. YAJUMAZE系モードのフレンド共闘対応＆ボス/家臣仕様変更
- **参加要請の拡充**: フレンド共闘ルーム接続中、YAJUMAZE（通常迷路・ボス戦）および PlayWars でも参加要請モーダル経由で共闘・対戦を開始できるようになりました。
- **World Enemy 家臣の新仕様**:
  - 出現から **2秒間の無敵状態** を付与しました。
  - 体力を **ボス最大HPの 1/20** に変更しました。
  - 共闘（マルチプレイ）時は家臣が **2体スポーン** し、それぞれ別々のプレイヤーを1体ずつ追跡します。
- **World Enemy 弾攻撃の新仕様**:
  - 青色弾頭のクールダウンを **2秒** に短縮しました。
  - 共闘（マルチプレイ）時は弾を **2発** 発射し、それぞれのプレイヤーへ向かって飛翔します。
- **獣王（Beast King）マルチ分裂仕様**:
  - 共闘（マルチプレイ）時は獣王が **2体に分裂** し、重複なしでそれぞれ別々のプレイヤーを狙います。
  - **ボス体力は2体の間で共有** され、どちらにダメージを与えても共有HPが減少します。

### 3. 新モード「PlayWars」実装
- **ポータル配置**: ホームベース正面壁の左側（`x = -12.8, z = -20.3`）に `PlayWars` ポータルとPDAマップアイコンを追加しました。
- **マップ・移動・操作**:
  - 通常ステージの2倍以上となる `96×96` の広大なフィールドに、高い外壁（高さ12m）と多数の立体遮蔽壁を配置しました。
  - 初期スポーンはマップの対角端（`(-38, -38)` と `(+38, +38)`）に設定しています。
  - 移動速度は通常時の **1.5倍**、必殺技ボタンの位置に **ジャンプボタン（PCはSpaceキー）** を配置しました。
- **機体・ステータス・エイム仕様**:
  - 購入済み（解放済み）かつ **Laser以外** の機体を選択して出撃できます（必殺技は使用不可）。
  - アップグレードに関わらず、一律 **HP 100 / 防御 10** 固定で対戦します。
  - エイム補正を大幅に弱め、遮蔽壁による射線判定（LOS）を導入しました。
- **ソロ（AI戦）/ マルチ（PvP）＆報酬**:
  - **ソロ時**: イージー（1.0倍）〜 INSANE（4.0倍）の4段階からAIの強さを選択して対戦。勝利で **200Y × 難易度倍率**（200〜800Y）を獲得。
  - **マルチ時**: 招待承諾時に互いの機体を選んで対戦。勝利で **100Y** を獲得。
