# Cooking With SPAA v5.8Ω

## v5.8Ω アップデート概要

### 1. RapidFire 3Dスキン（3パーツ分割GLB）追加
- `EXPERIMENTAL_3D_SKINS` に **`RapidFire`** を追加しました。
- **参照アセットパス（自動探索）**:
  - `assets/vehicles/vehicles_02/` または `assets/vehicles/vehicle_02/` 内の `hull.glb` / `turret.glb` / `gun.glb`（および `RapidFire_hull.glb` 等、`assets/models/RapidFire/` 配下も探索）
  - 組み立て座標は `config.json`（`turretPivot: [0, 1.18, -0.18]`, `gunPivot: [0, 1.62, 0.05]`, 仰角 `0〜90°`）に準拠しています。
- **ダミーフォールバック対応**:
  - 実GLBファイルが未配置・ダミーの場合は、メタリックシルバー＋赤ライン＋U字ツイン支持タワー＋ガトリング砲風の簡易3Dモデルが自動表示されます。

### 2. 三人称視点の壁貫通防止＆接近時自動1人称切り替え
- **壁貫通防止**: 三人称視点で壁や障害物に近づいた際、カメラが壁を通り抜けず内側の壁際で停止して追従するようにしました。
- **自動1人称切り替え設定**:
  - 壁際などでカメラと自機の距離が近づいた際（約 `2.6m` 未満）、自動で1人称視点へ切り替わり、離れると自動で3人称視点へ戻ります。
  - 情報機器（📱）→「👤 プレイヤー」内の **「視点設定（壁際接近で自動1人称）」** スイッチからON/OFFを切り替えられます（デフォルトON・自動保存）。
