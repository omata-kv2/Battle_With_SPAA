# Cooking With SPAA (v4.0 - Co-op Sync & Upgrade Overhaul)

空から来る謎の飛翔体を迎撃する3Dシューティングゲーム。
v4.0アップデート：
- 参加者のホストルーム転送同期：参加者がルームIDを入力して接続成功した際、自動的にホストのホームマップへテレポート・同期される機能を実装。
- 参加者データのローカルストレージ保存・ロード（ユーザネーム、スキン情報、アップグレード情報）。
- 共闘退出機能：ホストルームの共闘ポータルから「ルームから退出」ボタンを押すと、通信を切断し、共闘中に獲得したゴールドを自身の元ワールドのゴールドに正確に加算。
- 初回ユーザネーム入力：ゲーム初起動時（スタートボタン押下・ロード完了後）、10文字以内のユーザネーム入力を強制し保存。
- 共闘中の頭上ユーザネーム表示：プレイヤースキンの上に相手および自分のユーザネームスプライトを表示。
- スキンアップグレード機能の完全正常化：スキン変更パネルから詳細な各パラメータ（攻撃力・防御力・体力・連射力）のアップグレード画面・処理を完璧に統合。
