# Cooking With SPAA (v3.0 - Major Combat & Upgrade Update)

空から来る謎の飛翔体を迎撃する3Dシューティングゲーム。
v3.0アップデート：
- 戦闘ステージ刷新：敵ミサイルはマップ中央上空25マスから真下へ降下、戦闘機は8方向からマップ中央高さ5マスへ向かって進撃。
- バトル途中離脱（ホームへ戻る）ボタンを追加（共闘時は二人同時にホームへ帰還）。
- 敵HP制導入：ミサイルHP=1、戦闘機HP=2。
- スキン能力に「攻撃力」「連射力」を追加。
- スキンアップグレードシステム実装（攻撃力・防御力・体力・連射力）。連射力に応じた0.1秒間隔の拡散バースト射撃に対応。
