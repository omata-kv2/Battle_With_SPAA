# Cooking With SPAA v5.6

## v5.6 アップデート概要

### 1. 情報機器（PDA）UIの刷新
- **タクティカル端末デザイン**: 情報機器（📱）モーダルを、グリッド背景・発光ステータスLED・ガラスモーフィズム・アクセントラインを備えたSFタクティカル端末デザインへ刷新しました。

### 2. 全画面ガチャ専用画面の実装
- **専用画面へ遷移**: 情報機器内の「🎰 ガチャ」から、画面全体を使用する専用のガチャ画面へ遷移します。
- **上部バー**: 「← 情報機器へ戻る」ボタンと、所持ゴールド（`G`）・所持YAJUコイン（`Y`）のリアルタイム表示を設置しました。
- **左端サイドバー（半透明・開閉対応）**: 画面左端〜中央より左の範囲に半透明のガチャ選択欄（現在は「YAJUガチャ」のみ、今後の追加に対応した構造）を配置し、端末サイズに合わせた幅調整と展開/格納トグルに対応しました。
- **5秒ごとの目玉背景ショーケース**: 背景にUR以上の目玉景品（電磁防御システム・獣神化パワーストーン・水素爆弾・野獣型原子爆弾）を5秒ごとに自動で切り替えて表示します（画像未配置時は専用ホログラフィックカードを表示）。
- **下端中央 / 右下**: 下端中央に「1回引く（100 Y）」「10連引く（1,000 Y）」ボタン、右下に排出確率を確認できる「📊 ガチャの確率情報」ボタンを追加しました。

### 3. ガチャコスト変更・演出豪華化・音声再生改善
- **コスト改定**: 1連 `100 Y` / 10連 `1,000 Y` に変更しました。
- **演出強化**: USSR（`USSR.png`＋`USSR.mp3`）・yajUR（`inmu_king.png`＋`114514.mp3`）の演出時に、放射状光輪・レアリティオーラ・タイトルバナーを追加し、表示画像が2秒かけてフェードインしながら拡大して迫るズーム演出を実装しました。
- **音声アンロック**: ガチャボタン押下時に `<audio>` 要素を同期アンロックする仕組みを導入し、モバイルブラウザ等でも演出音が確実に再生されるようにしました。

### 4. 上部機体バナーの削除
- プレイヤープレートの表示と重複していた画面上部中央の細長い機体表示欄（`#modeBanner`）を削除し、画面上部をスッキリさせました。
