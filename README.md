# Cooking With SPAA (v2.9 - Online Co-op Update)

空から来る謎の飛翔体を迎撃する3Dシューティングゲーム。
v2.9アップデート：
- オンライン共闘機能（PeerJSによるP2P接続）を実装。
- ホームマップに「フレンド共闘」ポータル（半透明四角柱）を追加。
- 4桁のルームID発行および参加機能。
- 共闘モード：戦闘機の数がソロの5倍、全体スピード1.2倍。
- 共闘スコアは二人の合計、獲得ゴールドは合計スコアの0.8倍。
- プレイヤーの見た目：ソロモードでは自身を非表示（形すら生成しない）、共闘モードでは1マスの半分のサイズの立方体（部屋主: 赤、参加者: 青）を表示しお互いに視認可能。
