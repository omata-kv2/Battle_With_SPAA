# Cooking With SPAA (v4.2)

上空から降下するミサイルや8方向から迫る戦闘機を迎撃する3D防衛シューティングゲームです。

## v4.2 アップデート内容
- **全体チャット機能（左上UI）**:
  - 初期状態は左上の「💬」ボタンのみに縮小表示。タップでチャットパネルを展開／縮小可能。
  - 送信時刻をメッセージ末尾に小さく薄く表示（例：`（2026-11-19-20:20）`）。
  - 縮小中に新着メッセージ・募集が届くと、「💬」ボタン右上に赤い未読バッジを表示（展開すると消去）。
  - チャット履歴はゲーム起動中メモリに保持されスクロール閲覧可能。ゲーム終了（タブ閉じ・リロード）で個人画面のチャット履歴を初期化。
- **共闘募集の全体チャット連携**:
  - ホストが共闘ポータルで4桁ルームIDを発行後、「全体チャットで募集する」ボタンを押すとホスト名とルームIDが全体チャットに掲載。
  - ホストはモーダルを閉じてホームやスキン部屋で自由に行動したまま参加者を待機可能。
  - ホストがゲームを終了・切断・募集解除すると、全員のチャット欄から該当募集が自動的に消去されます。
