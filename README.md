## 2. v4.9 アップデート実装内容

1. **機体 `RapidFire` 固有能力タレット強化＆複数均等配置 (`js/config.js`, `js/state.js`, `js/modals.js`, `js/player.js`)**
   - アップグレードに **`タレット数増加`（初期Lv.1で1つ / 最大Lv.5で5つ）** を追加しました。
   - 固有能力 `AdditionalTurre` 発動時、マップ内のランダムな位置・角度に対してタレット同士が均等な距離をおいて自動配置され、時間終了で全基同時に消滅します。
   - タレットの攻撃力および連射力は、プレイヤーのアップグレード等も含めた能力値と同値で自動迎撃を行います。
2. **機体 `Laser` 通常攻撃方式の刷新＆タレット設置・Mk.1〜Mk.5個別照射システム (`index.html`, `style.css`, `js/config.js`, `js/state.js`, `js/ui.js`, `js/modals.js`, `js/player.js`, `js/app.js`)**
   - アップグレードに **`タレット数増加`（初期Lv.1で1つ / 最大Lv.5で5つ）** を追加しました。
   - バトル開始時は設置ボタン（`タレット設置 (0 / M)`）が表示され、タップするとマップ内に均等な距離感でランダムな番号（`Mk.1`〜`Mk.M`）が振られた四角錐タレットが自動設置されます。
   - 現在の最大数まで配置し終えると設置ボタンは消え、代わりに右下へ下から順に **`Mk.1攻撃` 〜 `Mk.5攻撃`** ボタンが出現します。
   - 各ボタンを1回タップすると3秒間（アップグレード時は強化時間分）照射し続け（終了後1秒CD）、連動する四角錐タレットの頂点から赤色レーザーがプレイヤー視点の十字線の先に向かってリアルタイム連動して伸び、0.1秒毎に接触した敵へプレイヤー攻撃力と同値のダメージを与えます。
