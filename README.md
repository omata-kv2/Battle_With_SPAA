# Cooking With SPAA (v4.4)

上空から降下するミサイルや戦闘機の迎撃、および高度100mからの空挺ミサイル降下作戦を楽しめる3D防衛・攻撃アクションゲームです。

## v4.4 アップデート内容
- **ミサイルモデルの上下反転修正**: 全ゲームモード（`FALL MISSILE` / `AIR STRIKE`）において、ミサイル（`Kh-35.glb` およびフォールバックモデル）の見た目の上下の向きを反転。`AIR STRIKE` の噴射炎もミサイルのノズル後端から正確に噴射されるよう調整。
- **クリア時の2秒間ホワイトアウト演出**: ゲームクリア時、画面が2秒かけて白くフェードアウトした後に結果画面（リザルト）が表示される演出を追加。
- **AIR STRIKE 360°全周視点カメラ**: 三人称カメラが水平360°だけでなく上下の仰角・俯角にも対応し、ミサイルの周囲360°全周（上空の母機から真下の目標まで）を一定の距離を保ったまま自由に見渡せるように改善。
- **AIR STRIKE ランダム目標配置＆障害物の大幅複雑化**:
  - 地上目標の位置が毎試合ランダムな座標に配置され、操縦による誘導が必須に。
  - 空中の障害物に、回転十字ブレード・中空ゲートリング・往復移動ウォール・多層スラローム群などの複雑な立体ギミックを追加し、特に高難易度（`INSANE` 等）の攻略歯ごたえを大幅に強化。
