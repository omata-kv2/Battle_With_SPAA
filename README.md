# Cooking With SPAA (v4.6)

上空から降下するミサイルや戦闘機の迎撃、および高度100mからの空挺ミサイル降下作戦を楽しめる3D防衛・攻撃アクションゲームです。

## v4.6 アップデート内容
- **防御力アップグレード成長値の変更**:
  - 防御力の1レベルごとの上昇値を **+1** に変更（体力は1レベルごとに +10）。
- **Laser（15,000 G）**:
  - **通常攻撃**: 目線の少し前方下から視線の先へ光線の柱（初期攻撃力2）を **3秒間** 連続照射（照射終了後 **クールダウン1秒**）。
  - **アップグレード**: 光線攻撃力(Max50) / スコア獲得上昇+5%/Lv(Max50) / 光線持続時間+0.2秒/Lv(Max10)
  - **固有能力 `NeverStopper`**（CD 10秒 / Max Lv.10）: 光線を持続照射し（Lv.1: 10.5秒 〜 Lv.10: 15.0秒）、光線半径倍率を拡大（Lv.1: 1.25倍 〜 Lv.10: 1.7倍）。
- **Automatic（20,000 G）**:
  - **通常攻撃**: 1秒ごとに自動追尾弾を発射。1発目は視線正面へ、2発目以降は視線から **60°** のスプリンクラー角度で射出し、弾同士のターゲットが被りにくいよう分散追尾。
  - **アップグレード**: 攻撃力(Max50) / 防御力+1/Lv(Max50) / 体力+10/Lv(Max50) / 弾数増加(Max10 / Lv.10で同時11発)
  - **固有能力 `MultiBurst`**（CD 20秒 / Max Lv.10）: 10秒間、戦闘機を最優先で狙う追尾弾へ変化し、追加弾を獲得（Lv.1: +1発 〜 Lv.10: +10発）。
- **Wirbelwind（20,000 G）**:
  - **通常攻撃**: 視線中央を中心とする `0.75 × 0.75` の正方形の4つの頂点からそれぞれ弾を発射。
  - **アップグレード**: 攻撃力(Max50) / スコア獲得上昇+5%/Lv(Max50) / 各頂点の弾発射数上昇(Max5 / 最大Lvで各頂点に+5発追加)
  - **固有能力 `GermanTech`**（CD 30秒 / Max Lv.10）: 上空の飛翔体を破壊（Lv.1: 12個 〜 Lv.10: 30個）。
- **Beast（81,000 G）**:
  - **通常攻撃**: クールダウンなしの純白弾を発射（強力な白色パーティクル演出）。
  - **アップグレード（全項目 Max Lv.810）**:
    - **信仰力**: 1Lvごとに攻撃力 +2 ＆ 防御力 +2
    - **GAY力**: 1Lvごとに獲得スコア +10%（通常のスコア上昇アップグレードより高倍率）
    - **聖人力**: 1Lvごとに体力 +20 ＆ 通常弾発射数 +1 ＆ 拡散能力追加
  - **固有能力 `BeastEyesPower`**（CD 1秒 / Lv.10でCD 0秒 / Max Lv.10）: 出現している飛翔体を全て破壊。
