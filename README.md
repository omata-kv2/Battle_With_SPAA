# Cooking With SPAA v5.8

## v5.8 アップデート概要

### 1. ロード画面のエラーバナー自動消去
- 起動エラー（赤字バナー）が表示された場合でも、その後問題が解消されてロードが進行した時点で赤字のエラーバナーおよびエラー表示を自動的に消去する処理を追加しました。

### 2. PlayWars 改善（AI・発射・マルチ弾同期・チームカラー）
- **発射ボタン・バトルループ修正**: PlayWars 中に発射ボタンが反応しない不具合およびソロBOTが停止していた分岐不具合を修正しました。
- **ソロモードBOT AI刷新**:
  - 使用機体は **Origin** に固定。
  - プレイヤーを発見すると **追跡**・ストレイフ・ジャンプを行い、HP低下時や近距離では **逃走** しながら赤い弾を発射します。
  - 障害物回避ステアリングを備え、難易度（イージー〜INSANE）に応じてAIのキレが変化します。
- **チームカラー統一＆マルチ弾同期**:
  - **ソロ時**: 自分の弾・レーザーは **青**、敵AIの弾は **赤** に統一しました。
  - **マルチ時**: 参加要請を出したホストは **青**、参加者は **赤** に統一し、通常弾・爆発・追尾弾・PlayWars専用レーザーのすべてが相手画面にも確実に描画されるよう同期を拡張しました。

### 3. PlayWars 機体・攻撃ルール調整
- **Laser 使用可能化**: PlayWars で `Laser` を選択可能にしました。
- **初期攻撃力固定**: 全機体の攻撃力・連射等の攻撃性能は、アップグレード値ではなく各機体の初期値（`baseAtk` 等）を参照します。
- **Explosion 調整**: 1発ごとのクールダウンを **0.5秒** に設定しました。
- **PlayWars専用 Laser 仕様**: タレットを設置せず、頭上（カメラ外）からプレイヤーの十字線方向へ直接レーザーを発射します。攻撃判定は **0.2秒ごと**、照射終了後のクールダウンは **1秒** です。

### 4. 全体変更（弾・エフェクトのコンパクト化）
- `Explosion` と `Laser` を除くすべての弾のサイズを約半分に縮小し、ヒット時のパーティクル・エフェクトも小さく抑えめに調整しました。
