## 2. v5.0 アップデート実装内容

1. **`Explosion` 通常攻撃チャージ再設定＆画面右端中央チャージメーター追加**
   - 最大チャージ時間を `3.0秒` に変更し、チャージ開始後はいつでもボタン（またはSpaceキー）を離して攻撃可能にしました。最大 `3.0秒` 到達時はボタンを離すまでチャージを保持し、離した瞬間に発射します。
   - `0.1秒` 刻みのチャージ秒数 × `5`（最大 `15m`）を基本爆発半径とし、アップグレード「爆発範囲増加（初期Lv.1: `0m` 〜 最大Lv.10: `+5m`）」を計算後の半径へ毎回加算します。
   - 画面右端中央に `0.0s`〜`3.0s`（`0.1` 刻み目盛）の専用チャージメーターを追加。非チャージ時は黒枠＋内部透明、チャージ中は赤い水が溜まる演出、最大到達で枠が僅かに発光します。
2. **共闘・マルチプレイ2回目以降開始不能バグ修正＆「もう一度リトライ」完全対応**
   - 1回戦終了後に送信中ロックフラグや前回ゲームの敵・エフェクト・スコア・状態フラグが残っていた問題を解消し、2回目以降も確実に開始できるように修正しました。
   - 「もう一度リトライ」押下時にゲーム終了画面が確実に閉じ、ソロ・マルチ双方で前回データをリセットして即座に再戦開始できるよう修正しました。
3. **短尺グラデーション弾道（`Laser`・`Automatic` 以外の全機体）**
   - 長いビーム状の弾道を廃止し、弾に近いほど色が濃く、後ろへ離れるほど細く透明に近づく短い弾道トレイルへ刷新しました。
4. **マルチプレイ出撃待機・参加要請（参加/拒否）・ホスト優先強制合流・全マップ情報同期**
   - 共闘中に誰かが出撃スタートを押すと待機状態になり、相手へ専用参加要請画面（参加 / 拒否）を送信。拒否時は出撃側のみのソロモードで開始し、同時押しで被った場合はホスト側の設定を優先して参加側マップをクリアした上で強制合流します。
   - 他プレイヤーの弾・弾道・爆発・設置タレット・レーザー照射・スキルエフェクトを含む全マップ情報をリアルタイム同期表示します。
