## 2. v4.8 アップデート修正内容

1. **スタート後のロード画面残留・操作不能バグの完全修正 (`style.css`, `js/ui.js`, `js/app.js`)**
   - `#startOverlay` が `.visible` 解除後も `display:flex` のまま最前面（`z-index:60`）で入力を遮断していた問題を修正し、ロード完了後に確実に非表示・操作可能になるよう修正しました。
2. **全機体の発射弾ビジュアル視認化＆着弾爆破エフェクトの実装 (`js/player.js`)**
   - 従来のビーム始点がカメラ中心と完全に重なり1点に潰れて見えなくなっていた問題を解消し、砲口オフセットからの外周エネルギービーム・白熱コア・飛翔する発光弾頭メッシュを描画するようにしました。
   - 着弾時爆破能力を持つ `Explosion` 機体の着弾時に、中心閃光球・爆風球体・二重衝撃波リング・四散する火球パーティクルによる爆破エフェクトが発生するようにしました。
3. **ゲームクリア画面およびスコア清算画面の正常表示 (`style.css`, `js/ui.js`, `js/app.js`)**
   - `#endOverlay` の表示クラス制御とホワイトアウト解除処理を連動させ、クリア時・敗北時ともにリザルト＆スコア清算画面が確実に前面表示・操作可能になるよう修正しました。
4. **バトル途中退出（ホームへ戻る）時のスコア・獲得ゴールド・状態完全リセット (`js/app.js`, `js/multiplayer.js`)**
   - 途中退出時にそのステージで得たスコアおよび獲得ゴールドを `0` に戻し（ソロ戦闘中に加算されていた分も取り消して保存）、WAVE・PEACE・機体状態・入力を初期化したうえでホームへ戻るよう修正しました。
