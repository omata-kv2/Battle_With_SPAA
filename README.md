# Cooking With SPAA — v2

## GitHubへの反映
**すべてのファイルを置き換えてください。** 前の版から `index.html` / `style.css` / `game.js` / `assets/enemy_shell.glb` を含めて全て置き換えます。

## 操作
- PC：マウスを押しながら動かして視点操作、WASDまたは矢印キーで移動、SpaceまたはPULSEで発射
- iPad・スマホ：画面左側約2/3をドラッグして視点操作。右側の方向ボタンで移動、PULSEで発射
- 移動速度はやや速めに設定

## 変更点
- スタートボタンの処理を3Dエンジンから分離し、読み込み失敗時にもメニュー操作を維持
- 開始前ロード画面と進捗表示
- 低負荷設定（アンチエイリアス無効、低電力優先、端末に応じた描画解像度）
- タッチ操作の選択・スクロール抑制
- 敵モデルの事前ロード

## 公開
GitHub Pagesで `main` ブランチのルートを公開してください。Three.jsはCDNから取得するため、初回起動時はインターネット接続が必要です。
