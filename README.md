# Cooking With SPAA v2.3

## GitHub Pagesへの反映
**すべてのファイルを置き換えてください。** ZIP内の `Cooking_With_SPAA_v21/` の中身をリポジトリ直下へ配置します。

## Three.js
`js/libs/three.module.js` が必要です。Three.js r160 (0.160.0) の `build/three.module.js` を配置してください。

## v2.3変更点
- 通常飛来物数を各ウェーブで約半分に調整（6, 9, 12, 15, 18）
- 第2ウェーブに戦闘機風ターゲット1機、第5ウェーブに2機
- 飛来速度を従来設定の約1.5倍に調整。戦闘機はさらに1.3倍
- 左端にアナログ移動スティックを追加、4方向ボタンを廃止
- 視点の上下角度を真上・真下まで拡張
- タッチ時の選択・長押しメニュー・ページ拡大ジェスチャーを抑止

## ダミーGLBについて
`assets/Kh-35.glb` と `assets/SU-27.glb` は配置確認用のダミーです。現段階の飛来物表示はThree.jsの仮形状で、これらのGLBを描画には使用していません。実モデルに差し替える段階でGLTFLoaderをローカル配置して読み込み処理を追加してください。

## 操作
- PC：WASD / 矢印キー移動、マウス視点、Space発射
- タッチ：左下スティック移動、画面右側ドラッグで視点、PULSE発射
