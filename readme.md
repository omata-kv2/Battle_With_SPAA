# Cooking With SPAA v5.5

## v5.5 アップデート概要

### 1. 情報機器（PDA）・HUDレイアウト刷新
- **チャットアプリ統合**: 情報機器（📱）内に「💬 チャット」アプリを追加し、画面左上の独立した 💬 ボタンを完全に削除しました。
- **HUD配置変更**:
  - **左上**: 情報機器ボタン（`📱 情報機器`）を配置し、チャット受信時には右上に未読の赤い点を表示します（情報機器内のチャットアプリボタンにも未読ドットを表示）。
  - **右上**: プレイヤー情報プレート（レベル・XPリング・プレイヤー名・プレイヤーコード・装備機体名）を移動しました。

### 2. ポータル・タッチパネル反応時間の統一
- ホームベースおよび各ルームのポータル・タッチパネルの起動反応時間を一律 **0.5秒** に統一しました。
- 起動ゲージバーは **機体格納庫の機体変更パネル** のみに表示されます。

### 3. テストルーム機能強化
- **DPS表示追加**: テストルーム滞在時のみ、画面左上（情報機器ボタンと重ならない位置）に直近1秒間の与ダメージ合計（DPS）を最大6桁想定のコンパクトな表示で追加しました。
- **帰還ポータル位置変更**: 「ホームへ戻る」ポータルを、プレイヤー初期スポーン位置（`z = 8`）の対岸となる反対側の壁沿い（`z = -16.5`）へ移動しました。

### 4. YAJUガチャ正式実装（報酬・確率・枠色・演出）
- **消費コスト**: 1連 `300 Y` / 10連 `3,000 Y`
- **排出率・報酬・枠色**:

| レアリティ | 排出率 | 報酬内容 | 枠色・発光 |
| :--- | :--- | :--- | :--- |
| **R** | 70% | `5,000 G` のみ | 水色枠 |
| **SR** | 25% | 石4種（全回復石・半分回復石・火力2倍石・移動速度上昇石）80% / `10,000 G` 20% | 黄色枠 |
| **UR** | 4% | 電磁防御・獣神化石 80% / `15,000 G` 20% | 光る赤紫枠 |
| **USSR** | 0.5% | 水素爆弾 | `#CD0000` 枠 ＋ 金色の輝き |
| **yajUR** | 0.5% | 野獣原爆 | 虹色枠 ＋ 茶色の輝き |

- **演出仕様**:
  - **R〜UR**: 演出なし。
  - **USSR**: 1秒暗転 → `USSR.png` が2秒かけてフェードイン → 暗転完了1秒後から `USSR.mp3` を4秒再生。暗転開始から画像フェードイン完了後1秒経過まで操作不能となり、完了後は自動でガチャ結果画面へ復帰します。
  - **yajUR**: 1秒暗転 → `inmu_king.png` が2秒かけてフェードイン → 暗転完了1秒後から `114514.mp4` を1回再生。演出中は操作不能となり、完了後は自動でガチャ結果画面へ復帰します。
  - **10連めくり**: 0.2秒ごとに1枚ずつ順番にめくられ、演出あり景品（USSR / yajUR）が出た時点でめくりを一時停止して演出を再生し、演出終了後に残りのめくりを再開します。

### 5. YAJU MAZE ボス戦バランス調整
- **プレイヤー機体体力の反映**: ボス戦開始時のプレイヤー最大HPに、現在装備中の機体体力（アップグレード強化値含む）が反映されるようになりました（回復系アイテムも機体最大HP基準で回復）。
- **ボス基礎攻撃力3倍**: 機体体力反映に伴い、ボスおよびボス戦取り巻きの基礎攻撃力を3倍に調整しました（難易度倍率 1.0x〜4.0x は維持）。
- **難易度別ボスHP変更**:
  - イージー: `500 HP`
  - ノーマル: `2,500 HP`
  - ハード: `5,000 HP`
  - INSANE: `10,000 HP`
